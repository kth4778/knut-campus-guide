# 팀원 수집 안내 — 건물 사진 · 꿀팁

앱의 건물 사진(2014년)을 뺐고, 꿀팁을 늘리고 있다. 사람이 직접 해야 하는 두 가지를 정리했다.

## 1. 건물 바깥 사진 찍기 (37곳, 1~2시간)

- **찍는 법:** 건물 정면, 가로 사진 1장. 건물 이름판이나 입구가 보이게. 맑은 날 낮, 사람 얼굴이 크게 나오지 않게.
- **파일 이름:** 표의 이름 그대로 (예: `E8_외관.jpg`). 휴대폰 원본 그대로 두면 크기는 내가 줄인다.
- **넣는 곳:** 저장소 `photos/buildings/` 폴더에 올리거나, 팀 드라이브에 모아 링크를 준다.
- **층별 피난안내도**는 `data-sources/buildings/floorplan-checklist.md` 그대로 (같이 찍으면 좋다).

## 2. 꿀팁 모으기 (동의 받은 것만)

에브리타임·인스타 글을 프로그램으로 통째로 가져오지 않는다 (이용약관 위반, 학생 글은 동의 없이 옮길 수 없음). 대신:

1. **앱 「꿀팁 제보」:** 팁 계정 화면의 「이 계정에 꿀팁 제보하기」나 새 게시물 화면의 링크. 제보는 GitHub 이슈(「꿀팁 제보」 라벨)로 들어온다. 팀이 확인하고 카드뉴스로 올린다.
2. **에브리타임 모집 글:** 팀원이 직접 글을 올려 댓글로 팁을 받는다(문구는 채팅에 정리). 받은 팁은 **우리 말로 다시 써서** 넣고, 아이디·닉네임·개인정보는 적지 않는다.
3. **학교 공식 인스타:** 공개 게시물을 보고 행사·혜택 정보만 메모(날짜, 링크)해서 넘긴다. 사진은 가져오지 않는다.

넘길 때 양식: `계정(학사·장학/생활·주거/교통/식사) · 제목 · 내용 2~4줄 · 출처(어디서 봤는지) · 확인한 날짜`
